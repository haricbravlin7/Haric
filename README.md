[**SugarRush — Repository**](https://github.com/Andy02062006/Sugarush)

- **RushBuddy AI Chatbot:** Provides an AI-assisted conversational interface.

<summary><strong>02. LifeOS Agent</strong> · Reinforcement Learning Environment for Personalized Tasks</summary>

### Project Overview

[**LifeOS Agent — Repository**](https://github.com/Janshafin/lifeos_agent)

LifeOS Agent is a reinforcement learning environment for **OpenEnv Theme 3.2 — Personalized Tasks**. It explores how language models can resolve cascading personal-life crises through structured, scored actions rather than generic advice.

The environment emphasizes decisions involving named people, concrete timelines, and priority-ordered stakeholder management, making agent responses more structured and objectively assessable.

### Key Features

- **Nine Handcrafted Scenarios:** A set of scenarios spanning three difficulty tiers.
- **Curriculum Learning:** Progressively increases task complexity.
- **Five Independent Reward Functions:** Evaluates agent behavior using separate, objectively verifiable reward signals.
- **Anti-Reward-Hacking Safeguards:** Three safeguards designed to discourage exploiting the training signal without producing useful responses.
- **Structured Action Environment:** Focuses on concrete decisions, timelines, and stakeholder priorities.
- **OpenEnv Integration:** Built around the OpenEnv framework for interactive agent environments.

### Engineering Highlights

- Explores reinforcement learning concepts through structured task environments.
- Uses measurable reward functions to assess task completion and decision quality.
- Investigates curriculum design for progressively more challenging scenarios.
- Addresses reward hacking as a problem in evaluating language-model agents.
- Emphasizes practical, verifiable outputs rather than purely subjective response quality.
